# AI Resume Screening System

An AI-powered resume screening system that analyzes resumes, compares candidate skills with job requirements, and generates useful screening results.

## 🚀 Features

- Resume upload and processing
- Resume content extraction
- Candidate skill analysis
- Job requirement matching
- Resume screening and scoring
- Candidate report generation
- Frontend interface for uploading resumes
- Python and Flask backend
- Machine learning-based analysis

## 🛠️ Technologies Used

- Python
- Flask
- Machine Learning
- HTML
- CSS
- JavaScript
- MongoDB
- PDF Processing
